# Car Sales Management System

A Python OOP and MySQL based Car Sales Management System.

## Technologies

- Python
- OOP
- MySQL
- MySQLdb
- SQL

## Features

- Add Car
- View Cars
- Search Car
- Update Car
- Delete Car
- Add Customer
- View Customers
- Sell Car
- View Sales
- SQL JOIN for sales information
